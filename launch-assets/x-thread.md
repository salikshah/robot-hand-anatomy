### Tweet 2 (The Philosophy: Demystifying Humanoid Dexterity)
`Characters: 271 / 280`

```text
2/ Most modern humanoid hand designs (Optimus Gen 3, LEAP Hand) are hidden inside proprietary CAD tools or heavy GPU simulator stacks like Isaac Sim.

We wanted an open, zero-install laboratory where anyone can orbit, actuate, and inspect every millimeter of mechanics.
```

---

### Tweet 3 (The Engineering Specs)
`Characters: 268 / 280`

```text
3/ The mechanical architecture:
• 22 DOF (4 per finger + 2 at wrist)
• 25 forearm motor units
• 3 tendons per finger (flexor + ab/adduct pair)
• Constant-length wrist gimbal (no cable slack)
• Rolling knuckle contact joints
• Compliant tactile skin on palm & fingertips
```

---

### Tweet 4 (The Anatomy Pedigree: Pure SVG via Separating Planes)
`Characters: 272 / 280`

```text
4/ The tech stack:

Built to test and extend the pure SVG anatomy engine inspired by @wheresryan22's brilliant anatomy repo.

Instead of a 3D canvas, depth order is solved mathematically per frame using separating planes between convex polyhedra. Crisp vectors at any zoom.
```
